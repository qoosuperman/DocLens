## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on qoosuperman/DocLens, managed with `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Four labels: needs-triage, needs-info, ready-for-agent, ready-for-human. No wontfix; issues that won't be actioned are deleted. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
